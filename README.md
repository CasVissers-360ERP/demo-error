# demo-error

Odoo 20 maatwerk voor de De Klerk demo.

- `deklerk_onderhoud`: onderhoudsgegevens op de verkoopregel voor de externe planningstool (locatie, contractvorm, bezoeken p.j., normtijd via klantklasse A/B/C, kleine route) en een uniek bezoek-ID op taken voor terugmeldingen.
- `deklerk_hr`: dagelijkse HR-signalering die standaard niet kan (verjaardagen, jubilea 12,5/25/40 jaar, salariswijzigingen, verlopende certificaten) als to-do voor de HR-verantwoordelijke.
